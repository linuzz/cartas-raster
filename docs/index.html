Cartas náuticas raster da DHN

Catálogo no formato RncProductCatalog para o plugin Chart Downloader do OpenCPN. As cartas são produzidas pela Diretoria de Hidrografia e Navegação (Marinha do Brasil). Este site só distribui os arquivos que a DHN publica gratuitamente; os direitos autorais continuam com a DHN.

URL do catálogo: BR_RNCProdCat.xml

No OpenCPN: Opções → Cartas → Chart Downloader → Add, e cole a URL completa https://linuzz.github.io/cartas-raster/BR_RNCProdCat.xml.

As cartas raster não substituem a carta de papel atualizada até o último Aviso aos Navegantes. Uso comercial exige autorização da DHN, por meio da EMGEPRON.
